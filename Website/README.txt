CodexReserve Website
====================

Open index.html in any modern browser.
No build step and no external dependencies are required.

Files:
- index.html    Main page
- styles.css   Responsive styling
- script.js    Copy buttons + reveal animation
- assets/      Provided CodexReserve screenshots + favicon

The install and source links point to:
https://github.com/yourarnav/CodexReserve

The included bar.png and pop.png are copied from the image assets supplied for this project.
